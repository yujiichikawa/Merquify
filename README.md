# Merquify — Mercado Simplificado

**Merquify** é um marketplace multi-vendedor construído com Laravel. O objetivo é criar uma plataforma robusta para **clientes**, **vendedores** e **administradores**.
---

## 📌 Tecnologias

- Laravel 12
- PHP >= 8.4.1  
- Tailwind CSS  
- Vite  
- Banco de dados MYSQL   

---

## Feature

- Autenticação multi-role 
- Sistema de gestão de produtos
- Aplicação de cupons 
- Avaliação e classificação de produtos  
- Integração com gateway de pagamento  
- Carrinho e checkout  
- Sistema de blog integrado ao ecommerce  
- Tracking de pedidos, histórico de transações, e sistema de newsletter

---

## 📚 Roadmap de Funcionalidades Futuras

- Módulo de devolução / reembolso de pedidos
